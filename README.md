# Lumos Fiber — Authorized Retailer (static site)

Pre-built static HTML, CSS, JS and images. No build step is required.

## Deploy on Vercel
1. Import this repository in Vercel.
2. Framework preset: **Other** — leave Build Command and Install Command empty, Output Directory `.`
   (already set in `vercel.json`).
3. Deploy.

Any static host (Netlify, Cloudflare Pages, S3, cPanel) works the same way — serve the repository root.
